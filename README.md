# 加油站班次交接

- 行业：石油
- 技术栈：Vue3、Vite、TypeScript、Element Plus
- 启动：`npm install && npm run dev`
- 构建：`npm run build`
- 规则/存储自检：`npm run check`

这是一个功能最小闭环前端项目，数据默认保存在浏览器 localStorage 中，方便后续扩展接口、权限、图表或地图能力。

## 发票票号台账

班次交接页新增“发票票号台账”，每班登记票号首号、尾号、开票金额与作废明细。实现按
**票号规则、存储、界面** 三层拆开，互不耦合，且未新增任何依赖：

| 层 | 文件 | 职责 |
| --- | --- | --- |
| 规则层 | `src/invoice/rules.ts` | 纯函数：票号解析/补零、班次时序、衔接/跳号/重号、跨日回绕、作废明细校验、占用段与尾号推算，不依赖 Vue 与 localStorage |
| 存储层 | `src/invoice/store.ts` | localStorage 唯一事实来源、占用与校验的派生数据、确认冻结、修正版本历史、操作拦截与被挡信息 |
| 界面层 | `src/invoice/InvoiceLedger.vue` | 登记表单、实时校验预览、台账列表、票号占用表、被挡操作明细、版本历史 |

业务规则：

- 票号为 8 位数字（00000000-99999999），作废必须填写票号与原因，作废票号须在本班号段内且不得重号；
- 班次按“日期 + 早/中/晚”排序，后班首号须紧接前班尾号；只有
  `99999999 → 00000000` 构成回绕，且只能跨日发生，全程最多一次；
- 命中跳号、重号、号段重叠、回绕违规或作废原因为空时，班次可以先存下，但保持“待复核”，确认入口冻结；
- 确认复核后票号与金额固定：直接修改、删除均被挡；调整只能“发起修正”——旧版本原样保留在版本历史，
  修正必须填原因，新版本回到待复核重新走全部校验；
- 切换班次筛选或刷新页面后，占用台账与版本历史均由持久化数据重新派生，不会错位；
- 每个被挡操作都展示：操作与班次、命中票号段、原值、新值以及全部命中校验（含机器可读 code）。

`scripts/check-rules.ts` 与 `scripts/check-store.ts` 是两层的场景自检（经 esbuild 临时打包到
node_modules/.cache 后由 node 运行，不参与前端构建，不引入运行时依赖）。
