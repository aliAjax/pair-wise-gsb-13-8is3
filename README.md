# 加油站班次交接

- 行业：石油
- 技术栈：Vue3、Vite、TypeScript、Element Plus
- 启动：`npm install && npm run dev`
- 构建：`npm run build`

这是一个功能最小闭环前端项目，数据默认保存在浏览器 localStorage 中，方便后续扩展接口、权限、图表或地图能力。

## 发票票号台账

顶部「发票票号台账」页签提供每班发票票号登记，与原班次交接页共用同一存储体系，独立成模块，未引入任何新依赖。

### 业务规则

- 每班登记：票号首号、尾号、开票金额、作废明细；每张作废发票必须填写原因。
- 衔接：后班首号必须紧接前班尾号；前班尾号到 99999999 后，跨日首号可回绕为 00000001，全周期最多回绕一次，同日不得回绕。
- 校验分级：
  - 硬校验（挡下操作）：票号格式/越界、首尾倒置、金额无效、作废票号不在本班段内、同日回绕、回绕超限、修正原因空。
  - 待复核（可保存/可修正但不能确认固定）：跳号、重号、作废原因为空、作废重号。
- 确认固定：无任何校验问题时可确认，确认后票号与金额锁定。
- 修正留痕：确认后的修正必须填修正原因，旧版本完整保留进版本历史，新版本重新进入待复核。
- 防错位：切换页签或刷新后，占用一览、待复核状态、版本历史与被挡操作均从 localStorage 重新推导。
- 被挡操作留痕：展示操作类型、票号段、原值、新值以及命中的校验项，刷新后保留。

### 代码结构（规则 / 存储 / 界面分离）

| 文件 | 职责 |
| --- | --- |
| `src/invoice/rules.ts` | 纯函数规则层：票号解析、班次衔接、回绕、跳号/重号、作废校验、占用链标注，不依赖 Vue 与存储 |
| `src/invoice/model.ts` | 数据模型：条目、版本快照、确认与修正（旧版入历史） |
| `src/invoice/store.ts` | 存储层：localStorage 读写、结构版本、种子数据、被挡记录持久化 |
| `src/invoice/state.ts` | 响应式状态编排：组合规则与存储，提供登记/确认/修正/删除/重算操作 |
| `src/invoice/Ledger.vue` | 界面层：登记表单、实时校验、占用一览、版本历史、被挡操作面板 |
